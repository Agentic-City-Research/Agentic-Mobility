# Security Policy

## Secrets

Never commit API keys, `.env` files, authorization headers, raw private prompts or provider responses containing personal data. CI must use the mock provider and must not make paid model calls.

## Reporting

Before a public release, replace this paragraph with a private security contact. Until then, do not publish a live credential in an issue; revoke it immediately and contact the repository owner privately.

## Supported version

Only the latest tagged release receives security fixes during the research-preview phase.
